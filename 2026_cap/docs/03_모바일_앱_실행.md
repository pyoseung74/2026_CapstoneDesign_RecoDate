# RecoDate 모바일 앱 실행

완성된 웹 화면은 `frontend/`에 그대로 유지한다. Android와 iOS 앱은 Capacitor 셸을 사용하며, 빌드 직전에 `frontend/`를 `mobile/web/`로 복사한다.

## 구성

- Android 네이티브 프로젝트: `android/`
- iOS 네이티브 프로젝트: `ios/`
- 모바일 빌드용 웹 자산: `mobile/web/`
- 모바일 복사 스크립트: `mobile/scripts/prepare-web.mjs`
- Capacitor 설정: `capacitor.config.json`

## 백엔드 주소

웹은 기본적으로 `http://127.0.0.1:8010`을 사용한다. 모바일 기기의 `127.0.0.1`은 PC가 아니라 기기 자신을 뜻하므로 앱을 동기화할 때 접근 가능한 백엔드 주소를 지정해야 한다.

Android 에뮬레이터에서 PC 백엔드에 접근:

```powershell
$env:RECODATE_MOBILE_API_URL="http://10.0.2.2:8010"
npm run mobile:sync
```

실제 휴대폰에서 같은 Wi-Fi의 PC 백엔드에 접근:

```powershell
$env:RECODATE_MOBILE_API_URL="http://192.168.x.x:8010"
npm run mobile:sync
```

운영 배포:

```powershell
$env:RECODATE_MOBILE_API_URL="https://api.recodate.com"
npm run mobile:sync
```

실제 휴대폰 테스트 시 백엔드는 외부 접속을 받을 수 있도록 실행한다.

```powershell
python -m uvicorn app.main:app --app-dir backend --host 0.0.0.0 --port 8010
```

## Android

Windows에서 Android Studio, Android SDK, JDK를 설치한 뒤 실행한다. Android Studio의 내장 JDK를 사용해도 된다. 현재 PC에는 Java와 Android Studio가 없으므로 APK 빌드는 도구 설치 후 가능하다.

```powershell
npm run mobile:android
```

Android Studio에서 에뮬레이터 또는 USB 연결 기기를 선택하고 Run을 누른다.

명령줄에서 디버그 APK를 만들 때는 `JAVA_HOME`이 JDK를 가리켜야 한다.

```powershell
.\android\gradlew.bat assembleDebug
```

## iOS

iOS 프로젝트는 생성되어 있지만 실제 빌드와 App Store 제출은 macOS와 Xcode가 필요하다.

```powershell
npm run mobile:ios
```

macOS에서 위 명령을 실행한 뒤 Xcode에서 시뮬레이터 또는 연결된 iPhone을 선택하고 Run을 누른다.

## 웹 변경 후 앱 반영

웹을 수정한 뒤 아래 명령만 다시 실행한다.

```powershell
npm run mobile:sync
```

## 배포 전 보안 확인

Android 운영 앱은 평문 HTTP를 차단한다. 같은 Wi-Fi 테스트를 위해 `android/app/src/debug/AndroidManifest.xml`의 디버그 빌드에만 HTTP 예외가 있다.

iOS 운영 앱은 `NSAllowsArbitraryLoads` 예외를 사용하지 않는다. iPhone 로컬 테스트도 가능하면 HTTPS 개발 주소를 사용한다.

`192.168.x.x`는 PC에 공유기가 할당한 사설 IP 주소 자리표시자다. 현재 PC의 주소는 PowerShell에서 아래 명령으로 확인한다.

```powershell
Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -like "192.168.*" }
```
